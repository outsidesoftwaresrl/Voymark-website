# Voymark website

Presentation site for [Voymark](https://github.com/outsidesoftwaresrl/Voymark) —
the world-passport travel app. *Every journey leaves a mark.*

## Stack

Pure static HTML/CSS. No framework, no server-side build — but the six
language pages are generated by a small script and committed.

- `index.html` — English landing page (generated)
- `fr/ es/ it/ de/ ro/` — the other five languages (generated)
- `scripts/build_i18n.py` — the generator: template + translations in one
  file. **Edit copy here, not in the HTML**, then run
  `python3 scripts/build_i18n.py` from the repo root and commit the output.
- `assets/style.css` — brand tokens (mirrors the app's `Theme.swift`, light + dark)
- `.github/workflows/pages.yml` — deploys `main` to GitHub Pages

## Deploying

Enable Pages once in **Settings → Pages → Source: GitHub Actions**.
After that, every push to `main` deploys automatically.
