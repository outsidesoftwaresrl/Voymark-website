# Voymark — SEO keyword focus list

Last updated: 2026-07-27. Owned pages are relative to the site root; every
page also exists under /fr /es /it /de /ro with translated copy, which is
itself long-tail coverage for non-English queries.

## How to read this

Each cluster maps to exactly one landing page so we never compete with
ourselves. The home page carries the brand + generic head terms; the four
explore pages each own one intent; privacy/terms exist for trust queries
and are noindex-worthy only in theory — we keep them indexed because
"voymark privacy" searches should land on our own words.

These qualify Voymark against competitors in body copy and meta
descriptions everywhere: **offline**, **no account**, **no subscription**,
**private / on-device**, **free**, **passport stamp**.
